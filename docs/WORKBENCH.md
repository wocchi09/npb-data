# 比較ワークベンチ

`workbench.html`（トップページとANALYST LABから移動）で次の7機能を提供します。

1. 期間比較：打者・投手、重ならない任意の2期間、相手左右、得点圏、球種、投球前カウント、コースを指定。
2. 変化検出：データ最終日を基準に直近30暦日とその前30暦日を比較。直球平均1.5km/h以上（各30球）、空振り率8ポイント以上（各50スイング）、球種割合10ポイント以上（各100球）。閾値に対する変化量で並べる探索候補であり、検定や因果推論ではない。
3. 配球順序：同一打席の連続投球番号のみ。前球の球種・コース→次球種。条件は次球に適用し、欠番をつながない。
4. 根拠への移動：比較指標・配球集計から対象打席を絞り込み、元の試合パスと打席IDでリプレイへ移動。
5. 条件保存：ブラウザのlocalStorageに最大50件。保存名付きで読込・削除。同期・サーバー保存は行わない。
6. 確かさ表示：打席数・球数・取得率・小標本表示・Wilson 95%参考区間。投球間の依存と多重比較は未調整。取得率の分母は収集済み対象球であり、全試合の収集率ではない。
7. 出力：期間・条件・指標・母数・球種比較グラフ・注意点をPNGで保存。取得率、参考区間、先頭30件の根拠リンクをMarkdownでも出力。

## 集計

- 元データ：`dataset/atbats.csv` と `dataset/pitches.csv`。試合・打席の識別子を維持。
- 同じ日付・試合ID・打席ID（投球はさらに投球番号）の重複は先頭1件に統一し、件数をmanifestへ記録。
- 不明な数値・真偽値はnull。欠損を0やfalseに置換しない。
- OPSは必要な成績項目がすべてある打席のみ。投手は被OPS。球種など投球条件指定時は該当球を含む打席の最終結果を使うため、「その球種だけの打率」などとは異なる。
- 空振り率は空振り数÷結果が判明したスイング数。ボール球スイング率はゾーン外かつスイング判定取得済みの球が分母。
- 球速は正の取得値のみ。直球平均は球種名「ストレート」の球のみ。
- 条件変更後は古い結果を隠す。保存・出力では画面に表示した条件と母数を維持。

## 更新と検証

`python scraper/build_workbench.py --season 2026` で `data/2026/dataset/workbench/` に選手・役割別JSONとindex.jsonを生成します。ブラウザは選択選手のファイルだけ取得します。既存の `build_analyst_lab.py` の最後からも実行するため、Daily/Backfill/Rebuildなどの既存経路で更新されます。

`node --test tests/workbench_model.test.cjs` と `python -m unittest discover -s tests -p test_workbench.py` で母数・欠損・期間・配球境界・リンク・データ生成を検証します。
