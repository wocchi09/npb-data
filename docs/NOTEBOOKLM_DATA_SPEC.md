# NotebookLM向けデータ項目仕様

## 共通方針

- 出力先: `data/notebooklm/`
- 文字コード: UTF-8（BOM付き）
- 欠損: 空欄。推測や0埋めは行わない
- 日付: `YYYY-MM-DD`
- 集計基準日: 収録済みの最終試合日または元データ更新日
- 重複単位: 選手成績はシーズン・選手キー、試合は試合ID、対戦は打者・投手の組み合わせ

## ファイル

### batting.csv（野手成績）

20打席以上の野手を1選手1行で収録します。シーズン累計の主要打撃成績、直近5出場のOPS、W-Impact、一軍登録日数を含みます。50打席未満はサンプル不足です。

### pitching.csv（投手成績）

3登板以上の投手を1選手1行で収録します。役割、投球回、勝敗・セーブ・ホールド、防御率、FIP、WHIP、直近5登板W-Impact、一軍登録日数を含みます。10登板未満はサンプル不足です。

### teams.csv（球団成績）

順位表を1球団1行で収録します。リーグ、順位、勝敗、ゲーム差、得失点、打率、防御率などを含みます。勝敗は `standings.json` を正とし、別集計から推測しません。

### games_latest.csv（今日の試合）

集計基準日を含む直近7日間の試合を収録します。試合ID、対戦、球場、得点、勝敗投手を含みます。未収集・未来の試合は収録しません。

### games_season.csv（シーズン全試合）

2026年の開幕から集計基準日までに収集できた全試合を収録します。日付や試合IDのない空行、および同一試合IDの重複は除外します。

### matchups.csv（対戦成績）

5打席以上ある全打者・投手の組み合わせを収録します。10打席未満はサンプル不足です。対戦専用スプレッドシートへ分離します。

### roster.csv（登録・抹消）

現在一軍登録中の選手と直近30日以内に抹消された選手を1選手1行で収録します。取得済み日ベースの登録日数、直近登録・抹消日を含みます。公示未取得日は日数に含めません。

### roster_season.csv（シーズン登録経験者）

2026年に一度でも一軍登録一覧へ掲載された全選手を1選手1行で収録します。集計基準日はデータ全体の締め日であり、その日だけの公示を意味しません。

### form_players.csv（好調・不調）

野手・投手について直近5出場と15出場を集計し、それぞれW-Impact上位25人・下位25人を収録します。欠場試合は窓に数えません。調子判定は115以上を好調、85以下を不調、それ以外を標準とする表示上の分類です。

### metadata.csv

シーズン、集計基準日、生成日時、公開元、欠損方針、軽量化条件をキー・値形式で収録します。

### glossary.csv（指標説明）

OPS、wRC+推定、FIP、WHIP、W-Impact、W-Value、サンプル不足、一軍登録日数の意味と注意点を収録します。

## W-Impactの注意点

W-Impactは平均100を基準とするサイト独自の総合貢献指数であり、WAR、UZR、NPB公式指標ではありません。守備範囲など取得できない項目は含めず、推測しません。詳細は [`W_IMPACT_SPEC.md`](W_IMPACT_SPEC.md) を参照してください。

## 公開URL

```text
https://raw.githubusercontent.com/wocchi09/npb-data/main/data/notebooklm/{filename}
```

`main` ブランチ上の固定パスなので、Apps Scriptの設定変更なしに毎日の内容が更新されます。
