# 分析ラボ仕様

分析ラボは、単なるランキングではなく「標本数・計算方法・限界」を同時に確認するためのページです。URLは `?view=analysislab` です。

## 実装指標

- 年齢曲線: 各年度7月1日時点の満年齢で集計。野手OPSは50打席以上、投手ERAは10回以上を年齢別に出場量で加重平均する。
- RE24: 24通りのアウト・走者状態からイニング終了までの平均得点を、収集済み打席から算出する。プレー価値は `得点 + 終了状態期待値 - 開始状態期待値`。
- 推定WPA: 回、表裏、点差、アウト、走者状態を使う。ロジスティック事前分布と同一状況の実績を30標本相当で縮小する。当サイト独自の推定値であり公式WPAではない。
- 条件分析: 球団、打者左右、投手左右、回、走者、アウト、ホーム／ビジターを任意に組み合わせる。50打席未満は参考値とする。
- 類似選手: 率指標をシーズン内で標準化し、ユークリッド距離から類似スコアへ変換する。野手50打席、投手10回相当未満は対象外。
- 予測検証: 日付の前70%を学習、後30%を検証に固定した時間順ホールドアウト。リーグ平均へ縮小した単純モデルを基準線とし、MAEを表示する。
- 品質監査: 件数、期間、主要列の取得率、既知の制約を表示する。

## 解釈上の注意

RE24の得点は打席結果に記録された得点表記と打点を利用するため、暴投など打席途中の得点を取りこぼす場合があります。年齢曲線は現在の選手プロフィールに含まれる選手を中心とするため、生存者バイアスがあります。予測値は将来の成績を保証しません。
